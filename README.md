# 罗姗 · 作品集

纯静态 HTML / CSS / JavaScript 网站，保留黑板、手绘插画与作品互动。

## 连续浏览

- 页面依次展示关键成果、豆包实习作品、广告作品、电商实践、经历与技能及联系方式。
- 核心数据、简历和职责使用静态 HTML 直接呈现，无需展开。故宫黑板默认展示大吉葫芦，通过四幅粉笔画切换文物的制作过程。
- `reading.css` 负责连续阅读布局；页顶导航和原有插画目录跳转到相应作品。图片放大和视频播放是可选交互。
- 抖音互动数据是 2026-09-16 的公开页面快照，不是实时统计。修改数据时同时更新对应数值、标签和统计日期；不要将点赞量与播放量相加。

## GitHub Pages

发布 `main` 分支根目录。资源使用相对路径，支持 GitHub Pages 项目网址。
无需构建，无需服务器密钥或后端服务。`.nojekyll` 保证静态文件直接发布。

## 资源与维护

- 图片使用 WebP，目录图标按显示尺寸优化。视频默认高清，原分辨率不变；保留原文件，并提供手动切换的 720P 流畅副本。
- `video-playback.js` 只为邻近视频预读元数据，悬停或聚焦时再准备播放；节省流量模式下跳过预加载。清晰度切换保留播放进度、音量和倍速，竖屏放大复用同一个播放器。
- `assets/media/video-variants.json` 记录原片及播放副本。使用 `python scripts/optimize-videos.py --ffmpeg /path/to/ffmpeg` 生成副本后检查画质；高清副本节省不足 10% 时继续使用原片。新增或重编码后同步更新 HTML 的视频地址。
- 正文字体保持原来的霞鹜文楷字形和字宽。`wenkai-page.woff2` 覆盖当前页面及动态界面的用字，其他字符继续按需加载旧分包。修改文案后可运行 `python scripts/subset-fonts.py --source /path/to/LXGWWenKai-Regular.ttf`（同版本 1.522），脚本会校验字形、字宽与行高。
- 首页人物图优先加载，插画保持静态；装饰边栏等人物图加载完成后再下载。下方便签、文物粉笔画和视频封面接近屏幕时再加载，未启用 JavaScript 时保留静态回退。
- 正式页面已移除临时文字与图片编辑器。内容通过源文件维护。
- 修改 CSS 或 JS 源码后运行 `node scripts/build.mjs`，再推送到 `main`，Pages 会更新。视频与插画仅用于本作品集展示。
- 第三方字体许可见 `assets/fonts/*-OFL.txt`；Lenis 许可见 `assets/vendor/lenis-LICENSE.txt`。
